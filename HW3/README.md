# HW3 – Internet of Things

This folder contains the solutions for **Homework 3** of the IoT course.  
Each part of the homework is organized in its own folder with a dedicated `README.md` explaining the task, description, and video demonstration.

---

## 📂 Structure
- **part 1/** → CoAP client–server alarm demo (server exposes `/alarm`, client sends GET/POST).
- **part 2/** → REST API–based hospital & blood bank management (HTTP, FastAPI).
- **part 3/** → MQTT + Node-RED + InfluxDB pipeline with simulated sensors and dashboard.
