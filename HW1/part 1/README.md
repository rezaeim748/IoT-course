# HW1 – Part 1

## 📌 Question
Using one of the Arduino microcontrollers (Arduino family), print your **full name** and **student number** on the **Serial Monitor**.

---

## 📝 Description
In this part, the Arduino board is programmed to send a simple text message containing the student’s name and student number to the Serial Monitor.  
The program initializes serial communication at `9600` baud rate and prints the message once when the board is powered on. This task demonstrates the basics of serial communication between Arduino and the computer.
