# HW2 – Internet of Things

This folder contains the solutions for **Homework 2** of the IoT course.  
Each part of the homework is organized in its own folder with a dedicated `README.md` explaining the task, description, and video demonstration.

---

## 📂 Structure
- **part 1/** → Question 6 (Zigbee Hello/Hi communication with LEDs and buzzer)  
- **part 2/** → Question 7 (Zigbee-based alarm system with keypad, snooze, and stop)  
- **part 3/** → Question 8 (Smart blind system with light sensor, Blynk slider, and servo motors)  
- **part 4/** → Question 10 (IoT electronic voting system with central and voting groups)  
- **videos/** → Demo videos for each part  

---

## 📌 Notes
- Each part has its **own README.md** with details.  
- The `videos/` folder contains demonstration videos linked in each part’s README.
