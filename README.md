# IoT-course

This repository contains my solutions for the **Internet of Things (IoT) course** homeworks.  
Each homework is organized in its own folder with sub-parts, source code, and a dedicated `README.md` explaining the tasks and solutions.

---

## 📂 Structure
- **HW1/** → Basic IoT and Arduino exercises  
  - Serial communication  
  - LDR and LED control  
  - Countdown timer with keypad and buzzer  
- **HW2/** → Advanced IoT systems  
  - Zigbee communication  
  - IoT alarm system  
  - Smart blinds with sensors and Blynk app  
  - IoT voting system  
- **HW3/** → IoT communication and data integration  
  - CoAP client–server alarm system  
  - REST API–based hospital and blood bank management  
  - MQTT + Node-RED + InfluxDB with simulated sensors and dashboards
